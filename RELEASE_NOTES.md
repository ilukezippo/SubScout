First release of **SubScout**: English & Arabic subtitles for your whole movie and TV-series library, from several subtitle sites.

### Highlights
- **6 sources with Auto fallback:** YTS Subs, SubDL (API), SubSource, OpenSubtitles, SubDL (website), Gestdown/Addic7ed
- **Only downloads what's missing:** the disk is checked first, so complete files never hit the network
- **Rate-limit aware:** it slows down before the quota runs out, skips paused sources, and retries them in a second pass
- **YIFY/YTS releases try YTS Subs first:** no quota, and the subtitles are timed to that exact release
- **Season packs:** the right episode is picked from the ZIP
- **Arabic Windows-1256 subtitles** are converted to UTF-8
- **Select all / none / missing,** live filter, sortable columns, per-file `EN ✓ AR ✗` status
- **Settings window** with three tabs:
  - **Sources:** order and on/off switches, API keys, with *Test* buttons for the keys and the OpenSubtitles login
  - **Themes:** 6 accent colours × 3 backgrounds, previewed live
  - **About:** app info, *Donate*, and *Check for updates*
- **Auto-update:** checks GitHub at start-up; *Update now* replaces the exe and restarts
- **Modern dark UI** (Segoe UI Bold), resizable log with *Copy log*, and Windows sounds on finish/error

### Download & run
1. Download **SubScout.exe** below. It's a single file and needs no Python or install.
2. Double-click it. The first time, Windows may show *"Windows protected your PC"* because the exe isn't code-signed: click **More info → Run anyway**.
3. Open **⚙ Sources** to add your free API keys (links are in the window).

Works on Windows 10 and 11 (64-bit).
